Privacy Policy

Madeleine - Last updated: 2026-08-11

Madeleine is an offline-first Android application for recalling and saving personal memories.

Data collection

Madeleine does not collect personal data and does not use accounts, analytics, tracking, advertising or payment services.

Data stored on the device

The application stores saved prompt identifiers, optional written answers, optional moods, favorite status, timestamps, language and theme preferences locally in its private application storage.

Data transmission and sharing

Madeleine does not automatically transmit data to external servers. A user may explicitly choose to share a prompt, a written memory or a text export. In that case Android displays its system share sheet and the user chooses the destination. Madeleine does not control how a destination selected by the user processes the shared content.

Data deletion

Users can delete individual memories or reset all saved memories from the application. Uninstalling Madeleine also removes its private local application data, subject to Android device backup settings.

Permissions

Madeleine does not request sensitive Android permissions and does not require internet access.

Children's privacy

The application does not knowingly collect personal data from anyone, including children. Any text entered remains local unless the device user explicitly shares it.

Changes

Material changes to the application or this policy will be published at this URL with a revised date.
