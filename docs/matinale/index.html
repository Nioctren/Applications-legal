Privacy Policy

Matinale - Last updated: 2026-11-08

Matinale ("the application") is an Android application.

Data collection

Matinale has no account or app-operated backend. The publisher does not receive your wardrobe, moods, agenda or settings. Weather requests send a position or city to Open-Meteo as described below.

Data storage

Wardrobe descriptions, moods, agenda events, manual city and settings are stored locally in the application's private storage. The daily weather forecast is cached for the current day only. Clearing application data or uninstalling removes local storage, subject to Android backup and restore settings. Android may include preferences in system backup or device transfer; Matinale cannot access that backup.

Data transmission

To display the weather, Matinale sends geographic coordinates to api.open-meteo.com. When you type a city, it sends that city name and the interface language to geocoding-api.open-meteo.com to obtain coordinates. Requests also specify forecast or geocoding options; they contain no account identifier, wardrobe, mood or agenda content.

Open-Meteo receives the request and the connection's IP address. Geographic coordinates and IP addresses can be personal data. Their processing is governed by Open-Meteo's terms and privacy information; Matinale does not guarantee the provider's retention practices. No app-operated server receives these requests.

Analytics, tracking, and advertising

The application does not use analytics, tracking, advertising identifiers, or advertising services.

Data sharing

The application does not share user data with third parties, apart from the weather request described above.

Permissions

INTERNET: fetch the weather forecast. ACCESS_COARSE_LOCATION: obtain an approximate position for the forecast. Location can be refused or disabled in Settings; the user can type a city instead and the rest of the application works without it.

Children's privacy

The application does not knowingly collect personal data from anyone, including children.
