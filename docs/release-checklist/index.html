Privacy Policy

Release Checklist - Last updated: 2026-07-24

Release Checklist ("the application") is an offline checklist manager for software releases.

Data collection

The application does not collect any personal data.

Data storage

All data you create (checklists and checklist items) is stored locally on your device using Android system preferences storage. This data never leaves your device.

Data transmission

  • No data is transmitted to external servers.
  • The application works fully offline.

Analytics and tracking

  • No analytics are used.
  • No tracking or advertising identifiers are used.
  • No third-party tracking libraries are included.

Data sharing

The application does not share your data with any third party. When you use the JSON export feature, the generated content stays on your device unless you choose to share it yourself.

Permissions

The application does not request access to camera, contacts, location, or other sensitive capabilities.

Children's privacy

The application does not knowingly collect any data from anyone, including children under 13.

Changes to this policy

If this policy changes, the updated version will be published at the same location with a new "Last updated" date.

Contact

Use the public contact page for privacy or legal questions.
