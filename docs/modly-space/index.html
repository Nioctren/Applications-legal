Privacy Policy

Modly Space - Last updated: 2026-07-28

Modly Space ("the application") is an Android application.

Data collection

The application does not collect personal data.

Data storage

All application data is stored locally on the user's device using the device's private application storage. This includes the widgets you add to your dashboard and their content, such as bucket lists and their items, and lightweight widget preferences (for example a Daily Challenge completion streak or a chosen zodiac sign for the Horoscope widget). A zodiac sign is treated as a preference only; the application never asks for or stores a birth date or any other identifying information. This data never leaves the device unless you explicitly export a backup file yourself.

Data transmission

Most features work fully offline and do not transmit user data to external servers. One optional feature is an exception:

Weather and Outfit widgets. If you add the Weather widget or the Outfit widget and enter a city name, the application sends that city name and the coordinates derived from it to Open-Meteo, a weather service operated from Switzerland, in order to retrieve public weather information. No account, device identifier, precise device location, or other personal data is transmitted. The application does not request location permissions; the city is entered manually. The most recent weather result is cached on your device so it can be shown offline. If you add neither widget, the application makes no network requests for weather.

Open-Meteo processes each request on its servers and, according to its documentation, may keep technical request logs, including the request IP address and the requested coordinates, for approximately 90 days to prevent abuse. Weather data provided by Open-Meteo is licensed under CC BY 4.0 and is attributed inside the application.

Analytics, tracking, and advertising

The application does not use analytics, tracking, advertising identifiers, or advertising services.

Data sharing

The application does not share user data with third parties.

Permissions

The application does not request sensitive Android permissions such as precise location, contacts, or camera. It uses only the standard Internet permission, and solely for the optional Weather widget described above.

Children's privacy

The application does not knowingly collect personal data from anyone, including children.
