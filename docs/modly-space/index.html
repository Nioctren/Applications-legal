Privacy Policy

Hello Modly - Last updated: 2026-07-27

Hello Modly ("the application") is an Android application.

Data collection

Hello Modly has no account or app-operated backend. The publisher does not receive dashboard content, identifiers, analytics, advertising data, or tracking events. Optional weather requests are processed by Open-Meteo as described below.

Data storage

All application data is stored locally on the user's device using the device's private application storage. This includes the widgets you add to your dashboard and their content, such as bucket lists and their items, and lightweight widget preferences (for example a Daily Challenge completion streak or a chosen zodiac sign for the Horoscope widget). A zodiac sign is treated as a preference only; the application never asks for or stores a birth date or any other identifying information.

Android backup and device transfer. The application allows Android's standard backup and device-transfer mechanisms to include its private preferences. Depending on the device and Google account settings, Android may copy the dashboard, bucket lists and items, widget preferences, app settings, and cached weather readings to the user's encrypted Google backup or directly to another Android device. This is controlled by Android and the user; Hello Modly has no account, cannot access the backup, and does not operate a cloud service. Users can disable Android backup in system settings.

The user can also explicitly export a JSON backup to a chosen file or to the Android clipboard. Clipboard content can be read by other apps, so file export is recommended for sensitive list content. Hello Modly never uploads a manual export.

Data transmission

Most features work fully offline and do not transmit user data to external servers. One optional feature is an exception:

Weather and Outfit widgets. If you add the Weather widget or the Outfit widget and enter a city name, the application sends that city name and the coordinates derived from it to Open-Meteo, a weather service operated from Switzerland, in order to retrieve public weather information. No account, device identifier, precise device location, or other personal data is transmitted. The application does not request location permissions; the city is entered manually. The most recent weather result is cached on your device so it can be shown offline. If you add neither widget, the application makes no network requests for weather.

Open-Meteo processes each request on its servers and, according to its documentation, may keep technical request logs, including the request IP address and the requested coordinates, for approximately 90 days to prevent abuse. Weather data provided by Open-Meteo is licensed under CC BY 4.0 and is attributed inside the application.

Analytics, tracking, and advertising

The application does not use analytics, tracking, advertising identifiers, or advertising services.

Data sharing

The application does not send user data to an app-operated backend or sell data. Optional weather requests are processed by Open-Meteo as described above, and Android may process encrypted system backups or device transfers as described in the Data storage section.

Permissions

The application does not request sensitive Android permissions such as precise location, contacts, or camera. It uses only the standard Internet permission, and solely for the optional Weather and Outfit widgets described above.

Children's privacy

The application does not knowingly collect personal data from anyone, including children.

Your choices and rights

You can view and edit your dashboard data and preferences directly in the application. You can export the versioned dashboard document to a file; clipboard export is available as a warned fallback because other apps may read clipboard content. Hello Modly never uploads a manual export.

You can delete the main document, application preferences, and weather cache from Settings > Backup > Erase all data. Uninstalling removes local application storage, subject to Android backup and restore settings. You can disable or delete Android backups through Android or Google account controls where available. Avoid using Weather and Outfit if you do not want requests sent to Open-Meteo.

Because Hello Modly has no account or app-operated backend, the publisher cannot retrieve, correct, or delete local content or Android backups it cannot access. Use the contact page below for privacy questions or rights requests concerning data processed by the publisher.

Retention and security

Local data remains until you edit, erase, uninstall, or restore it, subject to Android backup settings. The app uses Android private application storage and validates backup documents, but no software or device storage can be guaranteed absolutely secure. Prefer file export over clipboard for sensitive free text.

Privacy by design

Hello Modly minimizes data, permissions, and network access. Future external APIs, AI, cloud services, analytics, advertising, authentication, precise location, or sensitive permissions require a new privacy review and updated disclosure before release. The design follows the principles in the CNIL mobile application recommendations.
