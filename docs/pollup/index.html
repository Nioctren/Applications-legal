Privacy Policy

Poll Up - Last updated: 2026-08-12

Poll Up ("the application") is an Android application.

Data collection

The application does not collect personal data.

Data storage

Application data is stored locally on the user's device, in the application's private storage: the circles and member names the user creates, the results of the rounds played (votes, scores, titles), the trophies and daily streak derived from those results, and which member the user selected as themselves. The user can erase all of it from Settings > Delete all my data, or by uninstalling the application.

Data transmission

The application does not transmit user data to external servers. It has no account, no sign-in and no backend. When the user taps "share", the application renders an image on the device and passes it to the Android share sheet; the user alone chooses the destination.

Analytics, tracking, and advertising

The application does not use analytics, tracking, advertising identifiers, or advertising services.

Data sharing

The application does not share user data with third parties.

Permissions

The application does not request any sensitive Android permission. It does not access contacts, photos, location or device identifiers. This policy will be updated if permissions are added.

Children's privacy

The application does not knowingly collect personal data from anyone, including children.

Changes

Updates to this policy will be published at this URL with a revised date.
