Privacy Policy

Vago - Last updated: 2026-11-24

Vago ("the application") is an Android application and a browser-based Web application.

Data collection

Vago has no account or app-operated backend. The publisher does not receive your trip information or imported documents. Documents and notes you choose to store may contain personal or sensitive information.

Data storage

Trip names, destinations and dates, stays, addresses, booking references, contact details, access codes, transport information, packing lists, useful information and notes are stored locally. Android uses a SQLite database and private application storage. The Web application uses a browser-local database and browser storage; its data is separate from Android and may be removed by clearing site data, private browsing, storage pressure or browser policies.

The optional profile (name, avatar and nationality) and language and appearance preferences are stored locally on the device or in the browser. Nationality may be personal information; it is optional and is not transmitted by Vago.

Optional trip departure reminders are off by default and are available only in the Android app. If you enable them, Android asks for notification permission and Vago schedules local notifications containing the trip name and departure timing. This reminder information is not sent to Vago or any third party. You can turn reminders off in settings.

When you explicitly choose a PDF or image through the Android or browser file picker, Vago stores a private copy for offline use. The selected original is not modified or deleted. A document you import may contain passport, booking or other sensitive information; only import content you want stored in the application.

Android may include application data and documents in system backup or device transfer depending on your device settings. Vago cannot access that backup and does not operate a cloud service. The browser controls its own profile backups.

Data transmission

Vago does not upload trip data or documents. Trip planning, stored documents and bundled destination guides work locally. When you tap the exchange-rate refresh button, Vago sends the selected three-letter currency code to Frankfurter (api.frankfurter.dev) to retrieve the latest available reference rates against EUR and USD. The request does not include your trip name, dates, destination text, notes or documents. As with any network request, Frankfurter can receive your IP address. Rates are cached locally, are not refreshed automatically, and are not second-by-second live trading quotes. You can also enter rates manually.

Tapping an external destination-guide link opens your browser or another application. That service receives a normal web request and may process your IP address or other information under its own privacy policy; Vago does not attach your stored trip data or documents to those links.

Analytics, tracking, and advertising

The application does not use analytics, tracking, advertising identifiers, or advertising services.

Data sharing

Vago does not sell data or automatically share your local content with third parties. Exchange-rate requests are user-initiated and contain only a currency code. A file provider you choose in the system picker, an external website you open, or Android backup may use its own network and privacy practices.

Permissions

Import uses the Android or browser file picker for files you explicitly select, not broad access to your photo or media library. Android needs Internet access for the exchange-rate refresh and external links. Vago does not request camera, microphone, location, contacts or broad media/storage permissions.

Data deletion

You can delete documents or trips inside the application. Deleting an imported document removes Vago's private copy, not the original file selected through the picker. Clearing Android application data or uninstalling removes local application storage, subject to Android backup and restore settings. Clearing browser site data removes Web application storage. Copies held by other applications or backups must be managed separately.

Children's privacy

The application does not knowingly collect personal data from anyone, including children.
