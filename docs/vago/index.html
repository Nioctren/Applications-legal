Privacy Policy

Vago - Last updated: 2026-11-08

Vago ("the application") is an Android application.

Data collection

Vago has no account or app-operated backend. The publisher does not receive your trip information or imported documents. Documents and notes you choose to store may contain personal or sensitive information.

Data storage

Trip names, destinations and dates, stays, addresses, booking references, contact details, access codes, transport information, packing lists, useful information and notes are stored in a local SQLite database in application storage.

When you explicitly choose a PDF or image through the Android file picker, Vago copies that file into its private application documents directory so it remains available offline. The selected original is not modified or deleted. A document you import may contain passport, booking or other sensitive information; only import content you want stored on this device.

Android may include application data and documents in system backup or device transfer depending on your device settings. Vago cannot access that backup and does not operate a cloud service.

Data transmission

Vago does not automatically upload trip data or documents. Trip planning, stored documents and bundled destination guides work locally. Tapping an external destination-guide link opens your browser or another application. That service receives a normal web request and may process your IP address or other information under its own privacy policy; Vago does not attach your stored trip data or documents to those links.

Analytics, tracking, and advertising

The application does not use analytics, tracking, advertising identifiers, or advertising services.

Data sharing

Vago does not sell data or automatically share your local content with third parties. A file provider you choose in the system picker, an external website you open, or Android backup may use its own network and privacy practices.

Permissions

Import uses the Android file picker for files you explicitly select, not broad access to your photo or media library. Vago does not request camera, microphone, location, contacts or broad media/storage permissions.

Data deletion

You can delete documents or trips inside the application. Deleting an imported document removes Vago's private copy, not the original file selected through the picker. Clearing application data or uninstalling removes local application storage, subject to Android backup and restore settings. Copies held by other applications or backups must be managed separately.

Children's privacy

The application does not knowingly collect personal data from anyone, including children.
